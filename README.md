# 🌐 Multisahifali React Veb-Portal

Ushbu loyiha **React 19** va **React Router DOM** yordamida yaratilgan keng qamrovli multisahifali boshqaruv va foydalanuvchi portali.

## 🚀 Texnologiyalar

- **React 19**
- **React Router DOM v7** (`BrowserRouter`, `Routes`, `Route`, `Outlet`, `Navigate`)
- **CSS3**
- **Vite**

## 🌟 Tizim tarkibidagi sahifalar

1. **Autentifikatsiya:**
   - Kirish sahifasi (`/login`)
   - Ro'yxatdan o'tish sahifasi (`/register`)
2. **Asosiy panel (Root):**
   - Bosh sahifa (`/root/home`)
   - Toifalar (`/root/categories`)
   - Loyihalar ro'yxati (`/root/projects`)
   - Shaxsiy profil (`/root/profile`)
   - Sozlamalar (`/root/settings`)
3. **Portfolio sahifalari:**
   - Loyihalar ko'rgazmasi (`/portfolio/projects`)
   - Rezyume sahifasi (`/portfolio/resume`)
4. **Ijtimoiy sahifalar:**
   - Xabarlar va chat (`/chat`)
   - Maqolalar va postlar (`/posts`)
   - Foydalanuvchilar ro'yxati (`/users`)

## 💻 Ishga tushirish

```bash
# Kutubxonalarni o'rnatish
npm install

# Dev rejimida ishga tushirish
npm run dev

# Production uchun build
npm run build
```
